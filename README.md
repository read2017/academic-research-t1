## 论文概述

## 如何查看理论框架图

### 方法1：直接打开HTML文件

1. 在浏览器中打开 `theoretical_framework.html` 文件
2. 图表将自动渲染，显示理论框架的可视化表示

### 方法2：使用Mermaid Live Editor

1. 访问 [Mermaid Live Editor](https://mermaid.live/)
2. 复制 `theoretical_framework.mmd` 文件中的内容
3. 粘贴到编辑器中，图表将自动渲染

### 方法3：在Markdown中查看

1. 使用支持Mermaid的Markdown编辑器（如Typora、VS Code with Mermaid插件）
2. 打开 `paper_draft.md` 文件
3. 在Section 3.5中查看理论框架图
