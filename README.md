## 📚 写作流程详解

### Phase 0: 配置访谈
- 确定研究主题
- 选择论文类型
- 设置引用格式
- 配置输出格式

### Phase 1: 文献检索
- 设计搜索策略
- 筛选相关文献
- 创建注释书目
- 识别研究空白

### Phase 2: 结构设计
- 选择论文结构
- 设计章节大纲
- 分配字数
- 映射证据

### Phase 3: 论证构建
- 提炼中心论点
- 分解子论点
- 构建CER链条
- 识别反驳论点

### Phase 4: 全文起草
- 按章节撰写
- 整合引用
- 控制字数
- 自我审查

### Phase 5: 引用检查与摘要
- 引用格式检查
- 双语摘要撰写
- 关键词选择

### Phase 6: 同行评审
- 五维度评分
- 问题识别
- 修订建议

### Phase 7: 最终格式化
- 生成最终版本
- 质量检查
- 准备投稿
